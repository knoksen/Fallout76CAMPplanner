# CHANGELOG v5 - UI/UX Foundation Pass

## Hovedløft
Denne versjonen flytter appen fra en tett, lineær sidepanel-oppsett til en mer ryddig og rask arbeidsflyt med tydeligere informasjonsarkitektur og bedre tilbakemelding på canvas.

## Ny UI/UX-struktur
- Høyere visuell kvalitet i app-shell med tydelig toppheader og statuslinje
- Høyreside organisert i faner:
  - **Overview**
  - **Build**
  - **Library**
  - **Inspect**
- Ryddigere seksjonskort med bedre kontrast og hierarki
- Mørkere, mer Fallout-inspirert arbeidsflate uten å ofre lesbarhet

## Forbedret brukervennlighet
- Søkbart **Placed Items**-panel
- Lagfilter i item-listen
- Owner-drawn item-list med:
  - fargeswatch per item/layer
  - koordinater og rotasjon
  - tydelig LOCK-badge for låste lag
- Sterkere oversiktsinformasjon i prosjekt-headeren

## Canvas feedback
- Live hover-koordinater
- Live placement preview når du bygger
  - grønn/positiv visning for gyldig plassering
  - rød/varsling for ugyldig plassering
- Footer-hints på canvas med sentrale snarveier
- Oppdatert header på canvas med aktivt verktøy og mer prosjektinfo

## UX-mål med denne runden
- raskere scanning av status
- mindre friksjon når du veksler mellom analyse, bygging og bibliotek
- tydeligere forståelse av hva som skjer før du klikker og plasserer
- bedre grunnlag for neste steg: visitor flow, trap logic, minimap og prosjektkort
