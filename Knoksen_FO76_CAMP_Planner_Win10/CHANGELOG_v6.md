# CHANGELOG v6 – Visual Structure & Workflow

## New in v6
- Added a **workflow-first header bar** with five build stages:
  - Layout
  - Envelope
  - Systems
  - Defense
  - Polish
- Added a dedicated **Workflow** section in the sidebar to guide the user through a structured CAMP planning process.
- Added **Focus presets** for faster visual clarity:
  - All layers
  - Structure
  - Systems
  - Defense
  - Presentation view
- Added workflow-aware stage descriptions that update based on the active tool.
- Added focus summary text showing which layers and overlays are currently active.
- Improved top-level visual hierarchy so the app reads more like a real planning workstation than a generic editor.

## UX intent
This version is about reducing cognitive load.
Instead of presenting all tools and all layers as equally important at all times, the UI now helps the player move through the build in purposeful passes.

## Recommended usage
1. Start in **Layout**
2. Move to **Envelope**
3. Place **Systems**
4. Validate **Defense**
5. Finish in **Polish / Presentation**
