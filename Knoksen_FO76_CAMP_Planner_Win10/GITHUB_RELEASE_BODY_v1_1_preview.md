# FO76 CAMP Planner v1.1.0-preview

Planning-focused preview release for roadmap work on v1.1 and v1.2.

## What changed

- Quick duplicate zones, snap toggle, and per-slot blueprint library are integrated.
- Route planning expanded into an editable ordered workflow.
- Trap planning expanded into structured editable zones.
- Defense review notes are now persisted per project.

## Direct canvas editing (new in this preview)

- Drag visitor markers to move route points.
- Drag trap-zone body to move zone footprint.
- Drag trap-zone corner handle to resize zone footprint.
