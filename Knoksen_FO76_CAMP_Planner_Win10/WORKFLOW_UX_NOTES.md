# Workflow UX Notes

## Design direction
The planner should feel like a lightweight hybrid of:
- tactical layout board
- building planner
- defensive coverage analyzer
- presentation canvas

## Workflow model
The core UX model is stage-based building rather than flat tool dumping.

### 1. Layout
Purpose:
- establish footprint
- validate CAMP radius
- test pathing and expansion room

Primary tools:
- Foundation
- Select

Focus preset:
- Structure only

### 2. Envelope
Purpose:
- define shell and circulation
- close perimeter
- place stairs/doors/roof in structural sequence

Primary tools:
- Wall
- Door
- Stairs
- Roof

### 3. Systems
Purpose:
- add utility logic after geometry is stable

Primary tools:
- Workbench
- Power
- Light

Focus preset:
- Structure + Utility + Power

### 4. Defense
Purpose:
- validate perimeter control and turret lines

Primary tools:
- Turret

Focus preset:
- Structure + Defense + Power

### 5. Polish / Presentation
Purpose:
- final atmosphere
- vendor readability
- roleplay and aesthetic expression

Primary tools:
- Decor
- Vendor
- Resource
- Display
- Ally

Focus preset:
- Structure + Aesthetic + Commerce

## UX principles
- one dominant task at a time
- clear stage progression
- visual decluttering through focus presets
- preserve expert speed through toolbar + shortcuts
- avoid modal confusion when switching between CAMP logic and Shelter logic
